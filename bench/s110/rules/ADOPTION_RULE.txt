S1-10 ADOPTION RULE (pre-registered 2026-11-07 before any S1-10 boot; md5 recorded in PROGRESS.md)
Scope: choose {connector, --numa-bind policy, cpu bytes} for the production profiles (spec = RadixArk DFlash2 K=7 line of
/tmp/muse_wf/s1-9-L11_result.json fg.launch_args; ns256 = non-spec mns 256 + cap 256). Arms: SIM = SimpleCPUOffloadConnector,
NAT = OffloadingConnector + VLLM_KV_CACHE_LAYOUT=LBNHC, x bind B (--numa-bind) / N (none); controls OFF_N (production) and OFF_B.
All arms run on the production tree and host (no feature tree: no CTL boot needed); each arm at the production exact
--kv-cache-memory-bytes unless guard G4 trips (flag and bytes travel together; check_spec_launch.sh on every spec boot).
Metrics (all from the harness / reuse_driver.py, one protocol for every arm):
  DEC  = real-prompt greedy decode sweep (bench_sd.sh DATASET=real) c1/c16/c64/c128, 2 reps per boot: output tok/s per cell.
  REU  = reuse_driver cycle: GPU-pool-overflowing working set (ws-factor 1.5 x pool tokens, 32k-token documents, 4 clients),
         pass 1 cold, passes 2..3 = reuse passes: TTFT p50/p99 and prompt tok/s of passes 2+3 pooled; 64k/118k re-admission TTFT.
  HIT  = external prefix cache hit tokens / queried tokens in the reuse passes (/metrics delta), the proof that a hit happened.
Guards for any connector arm X (compared with the OFF arm of the SAME bind policy):
  G1 decode overhead: geometric mean over the 4 DEC cells of tok/s(X)/tok/s(OFF) >= 0.990 and no cell below 0.975.
     A failing arm gets ONE retry boot (and the OFF arm one more boot); the pooled values of both boots decide.
  G2 boot: time to READY at most +180 s over the OFF arm of the same bind policy.
  G3 host memory: no OOM kill, no watchdog trip, no populate stall (READY reached); peak anon+shmem of every GPU node
     <= node total - 4 GiB at the sized tier; worker RSS growth during the workloads < 2 GiB.
  G4 GPU memory: GPU free memory at READY not lower than the OFF arm by more than the production headroom above the floor
     (spec 24 MiB; ns256 100 MiB), else the exact --kv-cache-memory-bytes is re-derived with the S1-7 rule for the winner.
  G5 correctness: zero failed requests, zero preemptions caused by the connector, text sha of the reuse requests identical
     to the OFF arm (greedy) for every request that has an OFF counterpart, health 200 after the run.
Benefit (REU) for X vs OFF of the same bind policy: pooled passes 2+3 TTFT p50 ratio <= 0.70 AND prompt tok/s ratio >= 1.30
  AND TTFT p99 ratio <= 1.00 AND 118k re-admission TTFT ratio <= 0.70 AND HIT >= 0.90 of the cached prefix tokens.
Choice: among the arms passing G1-G5 and the Benefit test take the lowest REU TTFT p50; a difference under 5 % is a tie and
  goes to SIM (no code fix needed, per-rank exact bytes). Bind policy: B is adopted iff OFF_B passes G1 against OFF_N
  (pooled >= 0.990) AND the connector arm with B is not worse than its N twin on REU p50 by more than 3 %; if B fails G1 the
  connector's memory must still be node-local: adopt N plus a branch option that mbinds the connector's own allocation
  (numa policy fix) only when numa_maps shows more than 10 % of the connector pages off the GPU's node under N.
No arm passes the Benefit test -> deliver the best arm that passes G1-G5 (or offload off if none) with the evidence and say
  that offload gives no benefit on the reuse workload. AL is informational (replay cells have zero variance: scored by
  accept-count sampling error with Bonferroni if ever used as a guard); the per-cell decode guard is tok/s.
Sizing (step 3) is not an A/B: per node the largest per-rank size that leaves margin M (derived from the measured OFF_B
  worker/EngineCore/API-server host memory and the kernel watermark, recorded in sizing.md) under strict membind.
